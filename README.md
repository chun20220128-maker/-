# 校園廚餘管理

**[手機／電腦直接開啟系統](https://chun20220128-maker.github.io/-/)**

**[按這裡下載系統 ZIP](./campus-food-waste.zip?raw=true)**

## 開啟方式

1. 下載後按右鍵，選「全部解壓縮」。
2. 開啟解壓縮後的「校園廚餘管理」資料夾。
3. 對 `index.html` 按右鍵 → 開啟方式 → Google Chrome 或 Microsoft Edge。

也可以在此儲存庫按綠色的 **Code → Download ZIP** 下載所有檔案。

## 資料與功能

- 依資料擁有者要求，網站與下載版已內建 2026 年 9–11 月共 40 天、520 筆歷史登打資料；不包含原始 Excel 或菜單附件。
- 後續登打與菜單只儲存在目前瀏覽器，不會自動上傳或同步；請定期匯出完整備份。已內建的歷史資料會隨網頁提供。
- 先在標題旁的「班級設定」建立學年度，再登打或匯入歷史 CSV。
- 舊版資料可先匯出完整備份，再於本版頁尾匯入。
- 支援學年度班級與人數設定、歷年查詢、CSV 格式檢查與匯入、離線 PDF 菜單預覽。
- CSV 範例僅供練習；每換年級、每換日期，秤重順序皆重新從 1 開始。

## 2026 年 9–11 月實際登打資料

**[下載可匯入的完整 CSV](./campus-food-waste-2026-09-to-11.csv?raw=true)**

此 CSV 經資料擁有者同意上傳，共 40 天、520 筆實際紀錄：9 月 20 天、10 月 19 天、11 月 1 天（11/2）。此 CSV 亦獨立提供下載；相同資料已內建於手機網站與系統 ZIP，無須重複匯入。本機已有同日、同年級紀錄時優先保留，不覆蓋；若本機班級、廠商或休假設定不同，會顯示未補入提醒。

匯入方式：先在「班級設定」建立 115 學年度，七、八、九年級各設定 4 班；再按「匯入歷史資料」，選擇 CSV，預覽檢查通過後按「確認匯入」。已有正式資料時，請先匯出完整備份。

CSV 保留 Excel 原始累計秤重：9、11 月為榮彬，每箱扣 3.4 kg；10 月為愛欣，每箱扣 3 kg。各日期、各年級與教師的順序均各自重新從 1 開始。已排除 8/31，以及 10/23、11/3–11/30 僅有空箱重量的預填日期。若 10/23 實際為已確認零廚餘，請另於系統補登確認。

## Windows 單機安裝版

Windows 桌面版的來源與測試位於 [`desktop`](./desktop)。安裝檔通過 Windows 建置、安裝、啟動與解除安裝測試後，會提供在 [Releases](../../releases)。

使用 Windows 10／11 64 位元，可安裝到電腦，資料與菜單改以本機 SQLite 保存；不與手機自動同步。安裝、資料位置、備份與還原說明見 [Windows 安裝說明](./desktop/WINDOWS-INSTALLATION.md)。
